# Personal Developer Portfolio

A responsive personal portfolio showcasing my software development skills,
education, experience and selected projects.

## Tech Stack

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Lucide React
- Git and GitHub

## Features

- Responsive desktop and mobile design
- About, skills and education sections
- Work experience timeline
- Selected development projects
- Downloadable CV
- Contact section
- GitHub and LinkedIn links

## Installation

Clone the repository:

```bash
git clone https://github.com/Sihle-Tabede/personal-portfolio.git
cd personal-portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
